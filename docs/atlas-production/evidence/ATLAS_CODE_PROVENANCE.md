- **Scope:** proposed Maven `:atlas-sdk` artifact and Play and Enterprise application distributions, including generated outputs and resolved dependencies. Baseline audit: `MESHTASTIC_LICENSING_AUDIT.md`, commit `ea9f03d`; this ledger does not approve distribution.

Unknown chain of title, TAK origin, notices, source delivery and exact combination review prevent release approval. `REVIEWED` means evidence was inspected, not that legal clearance was granted. `THIRD_PARTY_LICENSED` identifies an upstream license, not fulfillment of its conditions. `OWNED` requires documentary chain of title, not a commit author name. No current component is marked `OWNED` on Git history alone.
