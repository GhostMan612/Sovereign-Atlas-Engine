# Navigation + compass tape

Default Navigate mode: map-first UI, locate, search, destinations, route preview, start/stop, voice mute, bearing compass tape, target markers, offline coverage indicator, GPS accuracy/stale banner. Distinguish device heading, GPS course, route bearing and magnetic vs true north; never silently substitute one. Ticks for cardinal/intercardinal headings, smoothly scrolling tape with accessibility fallback and reduced motion. No copyrighted game assets.

Routing: licensed OSM-derived graph or equivalent with documented processing/updates, driving/walking/cycling profiles, turn restrictions, snap confidence, route alternatives, maneuvers, ETA provenance, recalculation, voice guidance via Android TTS, interrupted GPS handling, no-route/no-coverage UI, storage budgeting. Offline navigation must work in airplane mode with preloaded graph; not simply Go-To straight-line distance. Live traffic/transit are explicitly future optional integrations unless licensed and implemented.

Acceptance: synthetic intersection turn restriction, one-way, no route, wrong-way, reroute, route resume, voice mute, GPS unavailable, stale fix, crossing anti-meridian, bearing wrap, screen-reader focus, 720px-class screen, radio-off device evidence.
