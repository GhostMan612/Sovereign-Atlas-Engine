# Layers / historical knowledge / tactical

Layer manifest: stable ID, type, source ID/version, CRS, bbox, zoom bounds, time validity, style, z-index, blend/opacity, attribution, license, local cache policy, failure/unknown state. Support multiple overlays simultaneously, deterministic draw order and compositing; basemap exclusivity does not restrict overlay count. Historical overlay slider compares epochs with provenance and uncertainty.

Historical dossier: place/person/event/structure/parcel records with normalized names, geometry, valid interval, evidence date, source URL or archival citation, source license, confidence and conflicts. Local search index, temporal filters, linked blueprints and source viewer. Do not assert exact historical boundaries without supporting georeferenced source. Separate private field annotations from public licensed data.

Tactical: optional MGRS/UTM/lat-lon, waypoints, tracks, bearings, rings, radio link budget, geofence, measurement and terrain-aware LOS only after DEM verified. Display uncertainty, datum, magnetic declination source/date and terrain resolution. Not a targeting or weapons system.
