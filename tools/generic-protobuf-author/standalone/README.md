# Generic varint and field-key evaluation

This is a standalone development project. It is not included in `:atlas-sdk`, either Android flavor, a publisher, or a distribution artifact. It provides unsigned 64-bit varint and field-key encoding and decoding using `protobuf-javalite:3.25.5`; it does not implement fixed-width fields, length-delimited fields, nested-message parsing, unknown-field skipping, or a Meshtastic codec.

The decoder checks up to ten bytes, rejects truncation and overflow, normalizes validated nonminimal encodings before invoking the runtime, and returns the original next offset. This project accepts nonminimal terminating encodings and wire-level field numbers 19000–19999, as required by the independent tests. Those choices differ from the strict, single-field illustration supplied for evaluation; they are not a claim that schema declarations may use reserved field numbers. Wire types 3 and 4 are accepted as keys; group matching is outside this project's scope.

From `apps/atlas-android`, with the repository's configured JDK and Android SDK environment, run `./gradlew.bat -p ../../tools/generic-protobuf-author/standalone test --offline --rerun-tasks --console=plain`. The project uses its own Gradle settings and does not depend on Atlas modules or generated messages. The test suite includes the existing eight independent acceptance tests and additional boundary and malformed-input tests.

The cached javalite JAR used here was not independently authenticated against an upstream checksum. Its parent POM declares BSD-3-Clause, consistent with the [upstream v25.5 license](https://github.com/protocolbuffers/protobuf/blob/v25.5/LICENSE); the cached JAR contains no embedded LICENSE or NOTICE.
